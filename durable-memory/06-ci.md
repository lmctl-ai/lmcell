# CI and releases

The matrix follows lmnum, lmbio and lmfluid: Linux x64/arm64, macOS x64/arm64, and MinGW Windows x64. Compiler @lmctl-ai/lmctl@0.2.369 is pinned. SDK and dependency pins, generated schema, physics assertions, deterministic exports, error handling and linkage are checked by test.sh. LF checkout is enforced for lockfiles, schema and SDK bytes.

A version tag rebuilds all five platforms and publishes only after every build succeeds. The release job checks the binary version against the tag before uploading five named executables plus LICENSE and THIRD_PARTY_NOTICES. Build jobs have contents-read permission; only release can write. Initial release evidence will be recorded after verification.
